# Sistema de Gestión Universitaria

Proyecto final del módulo Java Basics: una aplicación de consola para
administrar los profesores, estudiantes y clases de una universidad.

El sistema permite consultar profesores y sus salarios, explorar las
clases con su detalle de profesor y estudiantes, inscribir nuevos
estudiantes en clases existentes, crear nuevas clases y buscar en qué
clases está inscrito un estudiante a partir de su id.

El proyecto está organizado en capas (modelo, gestión e io) y aplica los
conceptos fundamentales de la programación orientada a objetos:
encapsulamiento, herencia, polimorfismo, constructores y atributos/métodos
estáticos.
